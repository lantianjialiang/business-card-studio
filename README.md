# 印记 · 名片工作室

印记是一款纯前端名片编辑器。可以从模板新建单面或双面名片，编辑文字、图片和二维码，再导出 PNG 或 PDF。

## 本地运行

需要 Node.js 18 或更新版本。

```sh
npm ci
npm run dev
```

`npm run build` 执行 TypeScript 检查，并生成静态发布目录 `dist/`。运行 `npm run preview` 可检查构建结果。网站使用哈希路由，可部署到静态站点的子路径。

## 部署到 GitHub Pages

1. 在 GitHub 仓库打开 **Settings → Pages**，将 **Source** 设为 **GitHub Actions**。
2. 将工作流推送到仓库的默认分支。每次推送到默认分支时，工作流会构建项目并发布 `dist/`。也可从 **Actions → Deploy to GitHub Pages → Run workflow** 选择默认分支手动部署。
3. 部署完成后，从 **Settings → Pages** 打开网站。

## 制作名片

1. 在「模板库」选择模板，或从「我的设计」打开已有名片。双面名片可在左侧切换正反面。
2. 双击文字即可编辑。选中图片后，可以裁剪原图、独立调整图片框和框内图片，也可以修改图层名称。二维码支持上传图片或输入内容生成。图片和二维码均可开启黑白模式。
3. 在图层面板开启「多选」，或按住 Shift 点选对象，再用「对象对齐」将它们对齐到画布或指定对象。选中至少三个未锁定的对象，可以水平或垂直等距分布。拖动对象时会显示吸附参考线，按住 Alt 可暂时关闭吸附。
4. 点击「导出」生成 3 倍分辨率的 PNG，或按名片成品尺寸生成 PDF。双面名片可分别导出，也可用「正反面合图」生成一张 PNG，并调整两面之间的分割线宽度。

用 Delete 删除选中的对象，Ctrl/⌘+D 复制，Ctrl/⌘+Z 撤销，Ctrl/⌘+Shift+Z 重做。方向键可将单个对象移动 1 像素，按住 Shift 可移动 10 像素。

## 保存、复用与迁移

设计和个人模板保存在当前浏览器。照片、Logo 和二维码图片也在浏览器内处理。需要备份或换设备时，可在「我的设计」导出项目 JSON，再从首页「导入项目」。

在「我的设计」选择「存为模板」，即可将当前设计保存到模板库。再次使用该模板会创建一份独立的名片。
