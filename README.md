# 印记 · 名片工作室

一个纯前端名片编辑器。模板和项目可从首页打开，编辑结果自动保存在当前浏览器中。照片、Logo 和二维码图片在浏览器内处理。

## 本地运行

需要 Node.js 18 或更新版本。

```sh
npm ci
npm run dev
```

`npm run build` 执行 TypeScript 检查，并生成静态发布目录 `dist/`。运行 `npm run preview` 可检查构建结果。网站使用哈希路由，可部署到静态站点的子路径。

## 编辑和导出

- 双击文字可在画布内编辑。点击图片占位可上传，也可以在属性面板上传或替换。填充模式支持拖动调整裁剪。
- 点击画布或图层选中元素。拖动元素可移动，拖动角点可调整大小，顶部手柄可旋转。锁定后可在属性面板解锁。
- 用 Delete 删除、Ctrl/⌘+D 复制、Ctrl/⌘+Z 撤销、Ctrl/⌘+Shift+Z 重做。方向键移动 1 px，按住 Shift 移动 10 px。
- 导出 3 倍像素 PNG 或按成品尺寸生成 PDF。双面名片可导出任一面或两面。
- 在「我的设计」复制、删除或导出项目 JSON。可在另一设备上导入 JSON 接着编辑。
